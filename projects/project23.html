16-Bit RISC Microcontroller on FPGA

A fully synthesizable single-cycle 16-bit RISC microcontroller written in Verilog HDL, with memory-mapped GPIO and timer peripherals, verified on FPGA.

Verilog HDL FPGA Computer Architecture RISC

Abstract

This project presents the complete design, implementation, and verification of a 16-bit Reduced Instruction Set Computer (RISC) microcontroller using Verilog HDL. The microcontroller integrates a 16-bit datapath, register file, ALU, program ROM, data RAM, and memory-mapped peripherals including GPIO and a timer. A single-cycle architecture was adopted to ensure deterministic operation and simplicity, making the design well-suited for educational and FPGA prototyping purposes.

Objectives

  • Design a synthesizable 16-bit RISC microcontroller using Verilog HDL.
  • Implement a single-cycle CPU architecture.
  • Integrate memory-mapped peripherals (GPIO and timer).
  • Verify functionality through simulation and RTL analysis.
  • Target implementation on an Intel Cyclone V FPGA.

System Specifications

  • Architecture: RISC, single-cycle
  • Data width: 16 bits
  • Instruction width: 16 bits
  • Register file: 4 × 16-bit general-purpose registers
  • Program memory: ROM (4K × 16)
  • Data memory: RAM (4K × 16)
  • Peripherals: GPIO (8-bit), timer

Overall System Architecture

The microcontroller consists of a central processing core connected to instruction memory, data memory, and peripherals through a shared address and data bus. Memory-mapped I/O is employed, allowing GPIO and timer peripherals to be accessed using reserved addresses within the data memory space.

Key Functional Blocks

  • Program Counter (PC)
  • Instruction ROM
  • Control unit with FSM
  • Register file (4 × 16-bit)
  • 16-bit Arithmetic Logic Unit (ALU)
  • Data RAM
  • GPIO peripheral
  • Timer peripheral

Instruction Format

Each instruction is 16 bits wide and follows a fixed-length format to simplify decoding and enable single-cycle execution: 

[15:12] Opcode
[11:10] Destination Register (Rd)
[9:8]   Source Register (Rs)
[7:6]   Source Register (Rt)
[5:0]   Immediate / Unused

ALU Functionality

The 16-bit ALU supports a wide range of arithmetic and logical operations including addition, subtraction, multiplication, division, bitwise operations, shifts, and comparisons. Status flags such as zero, carry, negative, greater-than, and less-than are generated for control and branching decisions.

RTL Operation (Single-Cycle Execution)

In every clock cycle, the processor fetches an instruction, decodes it, reads the required registers, executes the operation, writes back results, and updates the program counter. This guarantees deterministic timing and simplifies control logic.

Simulation & Verification

The design was verified using ModelSim and Quartus. Simulation confirmed correct operation of the ALU, register file, memory accesses, branching behavior, GPIO read/write operations, and timer functionality. RTL schematics further validated proper module integration.

Conclusion

A complete and fully synthesizable 16-bit RISC microcontroller was successfully designed and verified. The modular architecture follows standard microcontroller design principles and is suitable for FPGA deployment. The design can be extended with pipelining, interrupts, or additional peripherals for advanced applications.
